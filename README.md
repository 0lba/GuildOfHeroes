## Собственный проект

Тема проекта: каталог игр

Главный класс: Game

Почему этот объект нужен программе:
Класс Game описывает одну игру в каталоге. Он позволяет хранить вместе все сведения об игре, а не держать их в отдельных переменных. Благодаря этому каталог может содержать много игр, и каждая из них хранит собственное состояние независимо от остальных.

Какие данные хранит объект:

- Название игры
- Разработчик
- Год релиза
- Рейтинг

Какие значения задаются через конструктор:
Через конструктор передаются название, разработчик и год релиза

Какие значения можно задавать автоматически:
Рейтинг задаётся автоматически внутри конструктора значением 0. Новая игра ещё не имеет оценок, поэтому рейтинг по умолчанию равен нулю - это логичное начальное состояние для любой только что добавленной в каталог игры.
