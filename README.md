## 11 lab
**Пункт 10**  
1. Выбранное правило:  
- Рейтинг игры Rating должен находиться в диапазоне от 0.0 до 5.0 включительно
- Значения < 0.0 или > 5.0 недопустимы и не должны попадать в объект
- Внешний код не имеет права записывать Rating напрямую - только через метод mut_rating(double a), который проверяет диапазон
2. Где проверяется правило:  
- Объявление свойства: `public double Rating { get; private set; }` - чтение открыто, запись разрешена только внутри класса Game
- Конструктор `Game(string name, string developer, int year)` - задаёт начальное допустимое значение `Rating = 0.0`
- Метод `mut_rating(double a)` проверяет `if (a < 0.0 || a > 5.0) return;` - недопустимое значение отклоняется, Rating не меняется; иначе Rating = a
3. Входные и фактические значения при неправильном действии:  
- При вызове `GTA5.mut_rating(-1.0)` входное значение равно -1.0. До вызова Rating был 0.0, после вызова фактическое значение осталось 0.0 - действие отклонено, потому что -1.0 < нижней границы 0.0  
- При вызове `GTA5.mut_rating(10.0)` входное значение равно 10.0. До вызова Rating был 4.5, после вызова фактическое значение осталось 4.5 - действие отклонено, потому что 10.0 больше верхней границы 5.0  
- Для сравнения, допустимое действие `GTA5.mut_rating(1.0)` входное значение 1.0, до вызова Rating был `0.0`, после вызова фактическое значение стало 1.0 - действие принято, так как 1.0 попадает в диапазон 0.0-5.0  
- Попытка прямой внешней записи `GTA5.Rating = 100.0;` не выполняется вовсе: компилятор выдаёт ошибку, потому что set у свойства Rating объявлен как private. Фактического изменения значения не происходит - код даже не компилируется
