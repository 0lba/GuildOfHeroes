Получатель - yaroslav, поэтому Health -= damage меняет yaroslav.Health, а не artem.Health. Артёму метод не вызывали и его состояние не тронуто. Аргумент 25 попадает в параметр damage в сигнатуре TakeDamage, и вычитание идёт из здоровья Ярослава: 100 - 25 = 75.
2. return; в void-методе - ранний выход, ничего не возвращает, просто сразу завершает вызов.
    return Health > 0; в bool-методе - возврат значения: выражение вычисляется в true/false и передаётся в место вызова, метод завершается.
3. Вызвать GetInfo() и сохранить результат в переменную, не передавая в Console.WriteLine:
    ```
    string info = yaroslav.GetInfo();
    ```
    GetInfo() только формирует и возвращает строку, сам не печатает. Печатает её позже строка в Program.cs:
    ```
    Console.WriteLine(info);
    ```

# Собственный проект

Тема проекта: каталог игр

Главный класс: Game

Почему этот объект нужен программе:
Класс Game описывает одну игру в каталоге. Он позволяет хранить вместе все сведения об игре, а не держать их в отдельных переменных. Благодаря этому каталог может содержать много игр, и каждая из них хранит собственное состояние независимо от остальных.

Какие данные хранит объект:

- Название игры
- Разработчик
- Год релиза
- Рейтинг

Какие значения задаются через конструктор:
Через конструктор передаются название, разработчик и год релиза

Какие значения можно задавать автоматически:
Рейтинг задаётся автоматически внутри конструктора значением 0. Новая игра ещё не имеет оценок, поэтому рейтинг по умолчанию равен нулю - это логичное начальное состояние для любой только что добавленной в каталог игры.

Было добавлено метод для установки рейтинга у игры. Был проверен отказ на устнановку рейтинга -1. Были протестированы следующие значения: установить значение -1 и значение 1.
